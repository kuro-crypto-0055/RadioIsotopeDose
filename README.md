# RI NOTE

図面上の測定点を選び、数値を記録する端末保存型PWAの試作です。

## 使い方

1. HTTPSのアプリURLをSafariで開き、ホーム画面に追加します。
2. チーム内で共有された図面セット（`.rinote`）をiPadの「ファイル」に保存します。
3. ホーム画面からアプリを起動し、「図面セット」から読み込みます。
4. 図面名・地点数を確認し、「この図面セットを使用」を押します。
5. オフライン準備が完了したら、機内モードで再起動して確認します。
6. 地点番号をタップすると専用テンキーが開きます。確定時に端末へ保存します。

## データの扱い

- このリポジトリに図面・施設名・実際の地点配置・測定データは含みません。
- 図面セットは端末内で読み込み、IndexedDBに保存します。図面ファイルは送信しません。
- 測定値・図面をGitHubへアップロードしません。通常のアプリ配信リクエストはGitHub Pagesに届きます。
- 「測定せず」「測定不能」は一覧で区別し、出力の線量セルは空欄にします。行は残します。
- 数値は小数点以下2桁。ゼロは `0.00` として残します。
- 出力順は測定地点番号順です。コピー・CSV・図面入りバックアップに対応します。
- バックアップJSONは図面と記録を含みます。リポジトリへ追加しないでください。
- ブラウザデータ削除・端末故障などに備え、定期的にバックアップを保存してください。
- 正式な訂正履歴はありません。Google同期は以下の試作03仕様を参照してください。

## GitHub Pages

`Settings → Pages → Deploy from a branch → main / (root)` を選びます。ビルド・サーバープログラムは不要です。

ファイルはすべてリポジトリ直下に配置します。サブディレクトリ形式のPages URLに対応しています。

## 更新

更新時は `sw.js` のキャッシュ名を変更し、ファイル一式をまとめて配置してください。使用中のアプリは古いキャッシュを利用する場合があります。バックアップ後にオンラインで開き、アプリと同じURLのタブをすべて閉じてから再度開いてください。

## 試作段階

数値・空欄出力・図面セットの検証、端末保存、バックアップ復元を確認しています。実際のiPadでの6時間運用、手袋操作、Excelへの貼り付けは導入前に確認してください。


## 試作03：Google同期と端末内50回保持

- 端末内は作成日時が新しい50回まで。未同期も含め古い回を自動削除します。起動時・更新保存時・バックアップ復元時にも適用します。クラウド側の表や図面セットは削除しません。
- Google同期は利用者の操作でのみ実行します。OAuthクライアントIDと共通のスプレッドシートURLを各端末に設定してください。設定ファイルでチーム内配布できます。
- 図面画像は送信しません。測定地点番号・図面名・線量・測定日時の4列を、選択中の測定回ごとに送ります。Googleログインは利用者ごとで、同期先への編集権限が必要です。
- 同じ内容の再送は同じタブを確認します。修正後は別タブに新版を追加し、古い表を上書きしません。逆方向の同期・自動同期はありません。
- Google Identity Servicesは接続準備操作のときだけ読み込みます。トークンはメモリだけに保持し、設定ファイル・バックアップには含めません。
- この試作のOAuth権限は spreadsheets スコープです。Googleの許可画面では全スプレッドシートへの権限が表示されます。アプリのAPI要求は設定されたスプレッドシートIDだけに限定します。
- API認証や大学側の制限は設定後に実接続テストが必要です。Google認証に必要なライブラリはオフラインでは使いません。オフライン測定・CSV出力は従来どおり利用できます。

タブ名は測定回の作成日（日本時間）の YYYY-MM-DD。同日の別データは (2)、(3) を付けます。識別情報はシートのメタデータに保存します。旧形式のタブは同じ内容を再同期すると日付名へ変更します。

## 試作03.2：複数施設
- 図面セットから施設名を表示し、施設ごとに測定回を切り替えます。登録済み図面は再読込なしで選択できます。
- 同期タブ名は「YYYY-MM-DD 施設名」。旧日付タブは内容が同じまま再同期すると施設名付きに改名します。
- 図面セットversion 2で英数字地点番号・地点の文字色・施設名を指定できます。version 1の図面と既存バックアップも利用できます。
- 保存上限50回は全施設の合計です。

## 試作03.3：スミア確認
図面上の「スミア確認」をオンにすると線量ボタンのみ非表示になり、元図面を確認できます。オフで復帰します。図面切替中も維持し、アプリ再読込で解除します。記録や画像には変更を加えません。

## 試作03.4：図面優先の表示
見出し・余白を縮小し、表示設定と凡例を折りたたみます。狭い画面では施設・測定回・図面の選択も折りたたみます。「図面を全画面表示」はアプリ内で図面を拡大表示する方式で、ブラウザのアドレスバー等は残る場合があります。「全画面を閉じる」で復帰し、そのまま地点入力・スミア確認ができます。
