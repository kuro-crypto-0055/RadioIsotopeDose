# RI NOTE

図面上の測定点を選び、数値を記録する端末保存型PWAの試作です。

## 使い方

1. HTTPSのアプリURLをSafariで開き、ホーム画面に追加します。
2. チーム内で共有された図面セット（`.rinote`）をiPadの「ファイル」に保存します。
3. ホーム画面からアプリを起動し、「図面セット」から読み込みます。
4. 図面名・地点数を確認し、「この図面セットを使用」を押します。
5. オフライン準備が完了したら、機内モードで再起動して確認します。
6. 地点番号をタップすると専用テンキーが開きます。確定時に端末へ保存します。

## データの扱い

- このリポジトリに図面・施設名・実際の地点配置・測定データは含みません。
- 図面セットは端末内で読み込み、IndexedDBに保存します。ファイル送信処理はありません。
- 測定値・図面をGitHubへアップロードしません。通常のアプリ配信リクエストはGitHub Pagesに届きます。
- 「測定せず」「測定不能」は一覧で区別し、出力の線量セルは空欄にします。行は残します。
- 数値は小数点以下2桁。ゼロは `0.00` として残します。
- 出力順は測定地点番号順です。コピー・CSV・図面入りバックアップに対応します。
- バックアップJSONは図面と記録を含みます。リポジトリへ追加しないでください。
- ブラウザデータ削除・端末故障などに備え、定期的にバックアップを保存してください。
- 本試作にはGoogleスプレッドシートへの同期、ログイン、正式な訂正履歴はありません。

## GitHub Pages

`Settings → Pages → Deploy from a branch → main / (root)` を選びます。ビルド・サーバープログラムは不要です。

ファイルはすべてリポジトリ直下に配置します。サブディレクトリ形式のPages URLに対応しています。

## 更新

更新時は `sw.js` のキャッシュ名を変更し、ファイル一式をまとめて配置してください。使用中のアプリは古いキャッシュを利用する場合があります。バックアップ後にオンラインで開き、アプリと同じURLのタブをすべて閉じてから再度開いてください。

## 試作段階

数値・空欄出力・図面セットの検証、端末保存、バックアップ復元を確認しています。実際のiPadでの6時間運用、手袋操作、Excelへの貼り付けは導入前に確認してください。
